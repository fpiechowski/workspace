# D7 alternatives screen — round 1

Summary: Short screen of fork-base alternatives to T3 Code (pingdotgg/t3code: MIT, TypeScript, last push 2026-10-12, ~27k stars). Requirements: Windows desktop, Claude Code + OpenCode, workspaces that group several repos and several worktrees of one repo, app state exposed to agents through MCP or a CLI. **Vibe Kanban** comes closest on features. It is Apache-2.0, has documented multi-repo workspaces, a local MCP server that exposes projects/issues/workspaces/repos, and support for 10+ agents including Claude Code and OpenCode. Its risk is maintenance: Bloop shut down on 2026-04-10, the last release was 2026-04-24, and the last commit was 2026-09-19. **Pane** (AGPL-3.0) and **Emdash** (Apache-2.0) are the actively maintained Windows options. Pane exposes its state to agents through the `runpane` CLI and MCP. Emdash has not been shown to do either, and I found no multi-repo-per-task support in either one. **Superset** (ELv2, no Windows), **Conductor** (proprietary, macOS only) and **ivar** (CLI, macOS/Linux) are cut. ivar is still worth studying as the model for multi-repo worktrees. **OpenCode desktop** (MIT, Electron, Windows builds) is a single-agent client, not an orchestrator. Overall, nothing found clearly beats T3 Code as a base. Vibe Kanban is the one serious alternative on features, at the cost of a Rust+TS stack and a wound-down maintainer.

## Leads

- Vibe Kanban: read `docs/troubleshooting.mdx` for actual Windows status. Check whether the MCP tools that depend on the removed cloud (orgs/projects/issues) still work locally. Check whether tasks and dependencies (parent_issue_id) survived the move to local-only. Gauge commit cadence after 2026-09-19.
- Pane: read docs/PANE_MCP.md and RUNPANE_CLI_CONTRACT.md. Confirm the desktop shell (Electron?) and whether a workspace can group repos for a single task.
- ivar: use its "Hall" / "View Dir" model as the design reference for multi-repo worktree workspaces in a T3 Code fork. It could also be wrapped as a tool if Windows support arrives.
- Unexamined: openteams-lab/openteams (Apache-2.0, 629 stars, active 2026-10-11) and cachix/agentaps (Apache-2.0 Rust "universal GUI for coding harnesses", active 2026-10-12). Small multi-repo CLIs: jossmoff/grove, hanfour/multi-repo-agent (CLI + MCP companion), DogaOztuzun/branchdeck (stale since 2026-03).
- Emdash ADRs (docs/adr/0001 host-authoritative workspaces) could inform workspace-model design.

## Looked for, not found

- A published community roadmap for Vibe Kanban after the shutdown (search only, low confidence).
- An ivar desktop app or Windows build; ivar's source was not on npm and was only found via GitHub code search.
- Multi-repo-per-task support in Emdash, Pane or OpenCode desktop.
- Emdash exposing its own app state to agents via MCP/CLI.
- Any open-source Conductor license or Windows build.
- Any project combining Windows desktop + permissive license + multi-repo workspaces + agent-facing state MCP + active maintenance. Vibe Kanban meets all of these except active maintenance.
